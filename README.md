# Iris Dataset Analysis and Petal Width Prediction

##  Project Overview

This project uses the Iris dataset to analyze the relationship between petal length and petal width and build a Linear Regression model for predicting petal width.

The project demonstrates the basic workflow of a machine learning regression problem, including data preparation, model training, prediction, and evaluation.

## 📊 Dataset

The Iris dataset contains measurements of iris flowers, including:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

For this project:

- **Input Feature:** Petal Length
- **Target Variable:** Petal Width

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 🔬 Methodology

1. Loaded the Iris dataset.
2. Selected Petal Length as the input feature.
3. Selected Petal Width as the target variable.
4. Split the dataset into training and testing sets.
5. Trained a Linear Regression model.
6. Generated predictions on the test data.
7. Evaluated the model using regression metrics.
8. Visualized the relationship between actual and predicted values.

## 🤖 Machine Learning Model

**Linear Regression**

The model was used to understand and predict the relationship between petal length and petal width.

## 📈 Evaluation Metrics

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### Results

| Metric | Score |
|---|---:|
| MAE | 0.1731 |
| MSE | 0.0511 |
| RMSE | 0.2261 |
| R² Score | 0.9115 |

The R² score of **0.9115** indicates that the model explains approximately 91.15% of the variation in the target variable for this train-test split.
